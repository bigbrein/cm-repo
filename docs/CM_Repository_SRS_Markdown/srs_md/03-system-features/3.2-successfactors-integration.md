# 3.2 SAP SuccessFactors Integration

**Description:** The system must retrieve authoritative employee data from SAP SuccessFactors rather than requiring manual entry.

| ID | Requirement | Priority |
|---|---|---|
| FR-SF-1 | The system shall query SAP SuccessFactors to retrieve Employee ID and Employee Name whenever a user selects an employee. | Must |
| FR-SF-2 | The system shall auto-populate the Employee ID and Employee Name fields on the upload form upon employee selection, without requiring manual entry. | Must |
| FR-SF-3 | The system shall maintain a locally cached, periodically synchronized subset of SuccessFactors employee data (ID, name, department, employment status). | Must |
| FR-SF-4 | The system shall synchronize employment status changes (including termination) from SuccessFactors to support dashboard highlighting of terminated employees (FR-DASH-6). | Should |
| FR-SF-5 | Where supported by SuccessFactors' extensibility options, the system shall provide a linked or embedded view allowing a user to see an employee's CM documents from within their SuccessFactors profile. | Could |
| FR-SF-6 | The employee selection control shall support type-ahead search, alphabetical default ordering, and surfacing of recently selected employees. | Should |
| FR-SF-7 | The system shall allow manual entry of employee information as a fallback when an employee cannot be located via SuccessFactors search. | Should |
