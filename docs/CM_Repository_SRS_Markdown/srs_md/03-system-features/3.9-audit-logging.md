# 3.9 Audit Logging

**Description:** A detailed, immutable audit trail underpins compliance and dispute resolution.

| ID | Requirement | Priority |
|---|---|---|
| FR-AUD-1 | The system shall log all user logins, both successful and failed, including timestamp, IP address, and user agent. | Must |
| FR-AUD-2 | The system shall log every document upload, edit, download, and deletion, including the acting user and timestamp. | Must |
| FR-AUD-3 | The system shall log reviewer and, where implemented, approval actions on CM records. | Should |
| FR-AUD-4 | Audit records shall be append-only; the application layer shall not permit update or delete operations against audit log entries. | Must |
| FR-AUD-5 | Audit records shall be retained per the organization's records-retention policy (see [Appendix B](../appendix-b-assumptions.md) for the open dependency on this policy). | Must |
