# 3.8 Record Actions (Edit, Delete, Download)

| ID | Requirement | Priority |
|---|---|---|
| FR-REC-1 | The system shall allow authorized users to download the source file or generated document associated with a CM record. | Must |
| FR-REC-2 | The system shall allow authorized users to delete a CM record, subject to role-based permission, with the action captured in the audit log. | Must |
| FR-REC-3 | The system shall allow metadata edits (not file replacement) within a configurable post-upload window (e.g., 24–48 hours) by the original uploader or an administrator, with every edit captured in the audit log. | Should |
| FR-REC-4 | After the edit window has elapsed, the system shall require an administrator-level correction for any change, and shall log that correction on the record. | Should |
| FR-REC-5 | Document download URLs shall be signed and time-limited rather than permanent public links. | Must |
