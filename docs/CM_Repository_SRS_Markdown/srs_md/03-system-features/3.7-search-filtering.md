# 3.7 Search & Filtering

| ID | Requirement | Priority |
|---|---|---|
| FR-SRCH-1 | The system shall support searching CM records by Employee Name. | Must |
| FR-SRCH-2 | The system shall support searching CM records by Employee ID. | Must |
| FR-SRCH-3 | The system shall support filtering CM records by Active status. | Must |
| FR-SRCH-4 | The system shall support filtering CM records by Expired status. | Must |
| FR-SRCH-5 | The system shall support sorting search results by Date Issued, Employee Name, Employee ID, CM Type, or Expiry Date. | Should |
