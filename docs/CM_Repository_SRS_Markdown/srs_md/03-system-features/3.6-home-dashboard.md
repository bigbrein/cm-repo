# 3.6 Home Dashboard

**Description:** The dashboard is the primary working surface, showing CM records with search, filter, and sort.

| ID | Requirement | Priority |
|---|---|---|
| FR-DASH-1 | The dashboard shall display Active CM documents by default. | Must |
| FR-DASH-2 | Each dashboard row shall display Document Name, Employee Name, Employee ID, Document ID, CM Type, Status, Date Issued, and Expiry Date. | Must |
| FR-DASH-3 | The dashboard's default sort order shall be Date Issued, descending (most recent first). | Must |
| FR-DASH-4 | The dashboard shall support sorting by any displayed column. | Should |
| FR-DASH-5 | Each record shall expose a context menu offering Edit (where permitted), Delete (where permitted), and Download. | Must |
| FR-DASH-6 | The dashboard shall visually highlight rows belonging to terminated employees (e.g., in red), distinct from the Active/Expired status indicator. | Should |
