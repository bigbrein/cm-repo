# 3.10 Reporting & Analytics

**Description:** Standard reports give HR and management visibility into CM activity, respecting the same access restrictions as the dashboard.

| ID | Requirement | Priority |
|---|---|---|
| FR-REP-1 | The system shall provide an Active CMs report, organization-wide or filtered by department. | Should |
| FR-REP-2 | The system shall provide an Expired CMs historical report. | Should |
| FR-REP-3 | The system shall provide a CMs by Type report (Written / Verbal / Final Warning breakdown). | Should |
| FR-REP-4 | The system shall provide a CMs by Department report. | Could |
| FR-REP-5 | The system shall provide a Documents Uploaded by User report for workload and audit review. | Could |
| FR-REP-6 | The system shall provide an Expiring Soon report, showing CMs approaching expiry within a configurable window (e.g., 30 days). | Should |
| FR-REP-7 | The system shall provide a Monthly Upload Trends report showing CM upload volume over time. | Could |
| FR-REP-8 | All reports shall respect the same role-based and department-based access restrictions as the dashboard. | Must |
