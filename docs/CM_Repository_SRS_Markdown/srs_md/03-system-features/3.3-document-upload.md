# 3.3 Document Upload

**Description:** Authorized users must be able to upload one or many CM documents efficiently, with metadata captured accurately.

| ID | Requirement | Priority |
|---|---|---|
| FR-UPL-1 | The system shall support uploading a single CM document or multiple CM documents in one session. | Must |
| FR-UPL-2 | The system shall support file selection via drag-and-drop and via a file picker dialog. | Must |
| FR-UPL-3 | The system shall provide a rich text editor allowing a user to compose a CM letter directly within the application as an alternative to uploading an external file. | Should |
| FR-UPL-4 | The system shall allow a user to add additional files to an in-progress upload batch via a "+" control. | Should |
| FR-UPL-5 | The system shall attempt asynchronous metadata extraction from each uploaded file and pre-populate the upload form with detected values, without persisting unconfirmed values. | Should |
| FR-UPL-6 | The system shall process and display files within a batch in upload order. | Could |
| FR-UPL-7 | The system shall require the user to review and confirm (or edit) all auto-populated values before the record is saved. | Must |
| FR-UPL-8 | The upload form shall capture CM Type, Valid Period (Months), Employee ID, and Date Issued. | Must |
| FR-UPL-9 | Date Issued shall default to the current date/time and remain editable to support backfilling historical CM documents. | Must |
| FR-UPL-10 | The system shall support chunked/multipart upload for large files. | Should |
